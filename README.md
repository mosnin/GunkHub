# Agent Flight Recorder

Agent Flight Recorder (AFR) records the complete execution of AI agents as immutable, structured event graphs. Engineers use it to inspect individual runs, replay executions step-by-step, and compare behavior across versions — turning opaque agent failures into auditable, debuggable records.

This repository is the foundation monorepo. It establishes the workspace structure, shared contracts, ingestion SDK, and web application scaffold. It is designed to be incrementally filled in by focused follow-up builds.

## Install

```bash
# 1. Clone the repository
git clone https://github.com/your-org/agent-flight-recorder.git
cd agent-flight-recorder

# 2. Install all workspace dependencies
pnpm install

# 3. Copy environment variable template
cp .env.example .env.local
```

Edit `.env.local` and fill in:
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` and `CLERK_SECRET_KEY` — from your [Clerk dashboard](https://dashboard.clerk.com)
- `NEXT_PUBLIC_CONVEX_URL` — from your [Convex dashboard](https://dashboard.convex.dev)
- `BLOB_READ_WRITE_TOKEN` — from your [Vercel Blob storage](https://vercel.com/docs/storage/vercel-blob)

## Package Descriptions

### `apps/web` — Next.js Application

The user-facing web application. Built with Next.js 15 App Router, Tailwind CSS, and the Convex React client. Handles authentication via Clerk. Contains:
- Pages for browsing organizations, projects, agents, and runs
- Event log viewer (timeline and tree views)
- Replay walker UI
- Run diff viewer
- API routes for SDK event ingestion

**Owned by: Team C**

### `packages/contracts` — Shared Domain Types (`@afr/contracts`)

The leaf package. Contains all TypeScript type definitions, enums, and Zod schemas shared across the SDK, web app, and Convex functions. Imports from nothing else in this repo.

**Owned by: Team B**

### `packages/sdk` — Recording SDK (`@afr/sdk`)

The TypeScript SDK that agent authors instrument their code with. Provides a `FlightRecorder` class that wraps agent execution, records events, and batches them to the AFR ingest endpoint. Designed to be lightweight and runtime-agnostic.

**Owned by: Team D**

### `convex/` — Backend

Convex schema, queries, mutations, and actions. Handles event persistence, org-scoped data access, and blob artifact pointer storage. Not a pnpm workspace package — managed by the Convex CLI.

**Owned by: Team B**

## Contributing

This is a focused product with a deliberate, narrow scope. Before making changes, read `CLAUDE.md` — it defines the architectural rules, tenancy requirements, event log invariants, and what is explicitly out of scope for v1.

Key rules:
- Never mutate events — the log is append-only
- Every Convex query must be org-scoped
- `@afr/contracts` imports from nothing else in this repo
- Business logic belongs in service modules, not API route handlers
- All UI components must handle loading, empty, and error states

For architectural changes, create an ADR in `docs/adrs/` first.
